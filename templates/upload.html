Format 1 — Pipe Format

	1. What is RAM?|Random Access Memory

	2. What is CPU?|Central Processing Unit

Format 2 — 6-Line Format

	1. Artificial Intelligence enables
	computers to ______

	A) Cook food
	B) Behave like humans
	C) Repair phones
	D) Build houses
	B) Behave like humans

	2. Machine Learning allows
	computers to learn from ______

	A) Paintings
	B) Data and patterns
	C) Batteries
	D) Printers
	B) Data and patterns

Format 3 — Pipe MCQ Format

What is RAM?|Random Access Memory|Read Access Memory|Remote Access Memory|Random Allocation Memory|Random Access Memory

	question,choice1,choice2,
	choice3,choice4,answer

	Random Access Memory

📖 View Supported Formats

Standard Numbering

	1. What is a computer?
	Answer: An electronic device.

	2. What is software?
	Answer: Programs that run on a computer.

Colon Numbering

	1: What is a computer?
	Answer: An electronic device.

	2: What is software?
	Answer: Programs that run on a computer.

WAEC / NECO Style

	1(a) Define a computer.
	(b) Mention 3 uses.
	(c) Mention 2 input devices.

	Answer:
	(a) A computer is...
	(b) Education, Banking,
		Communication
	(c) Keyboard, Mouse

Multi-Line Answers

	1. Explain Python.

	Answer:
	Python is a high-level language.
	It is interpreted.
	It is widely used.

	2. Explain Flask.

	Answer:
	Flask is a web framework.
	Used for building web applications.
